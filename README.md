> **GitHub Pages에 바로 배포할 수 있는 영어 직독직해·낭독 학습 홈페이지**  
> Core Reading 30편(CEFR B1–B2) + University 30편(CEFR C1)

## 1. 제공 콘텐츠

| 항목 | 실제 포함 수량 | 비고 |
|---|---:|---|
| Core Reading | 30편 | 기초·중급·심화 직독직해 |
| University Track | 30편 | 학술 영어, 논증·연구 보고·자료 해석 |
| 전체 원문 | 60편 | 원본 마크다운을 빠짐없이 포함 |
| 문장별 영어·한국어 | 1,759문장 | 문단별 2회차 직독직해 |
| 청크별 영어·한국어 | 9,383개 | 문단별 1회차 직독직해 |

두 ZIP에 있는 첫 번째 트랙(01–30편)은 중복이므로 한 번만 수록했습니다. 두 번째 ZIP에 들어 있는 원본 마크다운 62개(학습 60편 + 색인 2개)를 `source/`에 그대로 보관했습니다. 서비스에서는 `content.js`에 미리 변환한 자료를 사용합니다. 사이트 실행 시 외부 서버에서 학습 콘텐츠를 받아 오지 않습니다.

## 2. 바로 실행하기

**방법 A — 가장 간단한 실행 (Windows / macOS):** 압축 파일을 풀고 `index.html`을 브라우저에서 여세요. 다만 PWA 설치·캐시 기능은 `https` 또는 로컬 서버에서만 동작하며 브라우저에 따라 로컬 파일 접근 동작이 다를 수 있습니다.

**방법 B — 로컬 서버 실행 (권장):** Python이 설치된 경우 아래 파일을 이용하세요.

- Windows: `START_WINDOWS.bat` 더블클릭
- macOS / Linux: 터미널에서 `bash START_MAC_LINUX.sh`
- 또는 직접: `python -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속

`uv`, Python 패키지, Node.js, 빌드 도구는 **필요하지 않습니다.** 로컬 서버를 띄우는 경우에만 Python이 사용됩니다.

## 3. GitHub Pages 배포

1. GitHub에서 새 저장소를 생성합니다(예: `chunk-reading-studio`).
2. ZIP 압축을 풀고 **그 안의 파일 전체를 저장소 최상위(root)에 업로드**합니다. `index.html`, `app.js`, `styles.css`, `content.js`, `service-worker.js`, `manifest.webmanifest`, `assets/`가 같은 상대 경로를 유지해야 합니다.
3. 저장소에서 **Settings → Pages → Build and deployment**으로 이동합니다.
4. **Source = Deploy from a branch**, **Branch = main**, **Folder = /(root)**를 선택하고 저장합니다.
5. 배포가 완료되면 `https://사용자이름.github.io/저장소이름/`에 접속합니다. (공개 설정과 배포 소요 시간은 GitHub 계정·정책에 따라 달라질 수 있습니다.)
6. **비밀번호 `redpass`**를 입력합니다. 이 브라우저에서 7일 로그인 유지를 선택하거나, 현재 탭 세션에서만 사용할 수 있습니다.

모든 경로는 상대 경로이므로 GitHub Pages의 하위 프로젝트 저장소에서도 동작합니다. GitHub Pages가 기본적으로 HTTPS를 제공하는 경우 서비스 워커를 이용해 열어 본 사이트 자산을 오프라인 캐시에 저장합니다.

## 5. 연속 듣기 사용법 (v1.1 신규)

대시보드 또는 `전체 학습` 화면에 **「30편 · 60편 연속 듣기」** 패널이 있습니다. 개별 학습편의 청크·문장 학습 화면에서도 관련 옵션을 조정하고 해당 과정 30편 또는 60편 듣기를 시작할 수 있습니다.

1. `듣기 단위`를 선택합니다. **청크별**은 의미 단위 영어/한국어 청크를, **문장별**은 통문장을 읽습니다. 기본값은 청크별입니다.
2. `영어 다음 한국어도 듣기` 체크박스를 켜면 각 청크(또는 문장)를 **영어 → 한국어 → 다음 영어 → 다음 한국어** 순서로 낭독합니다. 해제하면 영어만 재생합니다. 한국어 음성 품질은 사용자 기기의 한국어 TTS 설치 여부에 따라 달라집니다.
3. `읽는 청크 화면 중앙 자동 스크롤`을 켜면 낭독 중인 문장 또는 청크에 강조 표시가 붙고 현재 항목으로 화면이 부드럽게 이동합니다. 끄면 자동 이동하지 않습니다. **기본으로 켜져 있습니다.**
4. 아래 원하는 범위의 버튼을 선택합니다.
   - **Core 30편 연속 듣기:** 01~30편
   - **University 30편 연속 듣기:** U01~U30편
   - **전체 60편 연속 듣기:** Core 01~30편 이후 University U01~U30편
5. 새 학습편의 첫 구간이 시작되면 해당 페이지로 자동 전환됩니다. 하단 재생기에는 현재 편 번호, 제목, 청크/문장 위치와 전체 낭독 진행률이 표시됩니다. **이전 편 / 일시정지·계속 / 다음 편 / 정지** 버튼으로 조작할 수 있습니다.
6. 처음부터 다시 듣고 싶으면 동일 범위의 재생 버튼을 다시 누르세요. 듣기 옵션 변경은 이미 시작된 재생 목록이 아니라 다음 재생 시작 때 반영됩니다. 화면을 다른 메뉴나 모드로 수동 전환하면 재생은 정지합니다.

**중요:** Web Speech API(TTS)는 MP3처럼 백그라운드 연속 재생을 보장하지 않습니다. 화면 잠금, 절전, 탭 비활성화, OS 음성 서비스 및 브라우저 업데이트 등의 이유로 긴 재생이 중단될 수 있습니다. 휴대폰에서 장시간 연속 청취할 때는 가능하면 브라우저를 전면에 유지하고 화면을 켜 두세요. 이 기능은 네트워크가 필요 없는 합성 엔진을 보장하지 않으며, 녹음 음원 다운로드 기능도 아닙니다.

## 6. 브라우저 TTS 안내

사용자가 제공한 ZIP은 **마크다운(.md) 문서만 포함**합니다. 실제 음성 녹음(mp3/wav)은 없으며, 사이트의 영어 듣기는 `SpeechSynthesis`(브라우저·운영체제 음성합성) 기능입니다. Windows Edge/Chrome, macOS Safari/Chrome 등에서 음성 종류와 품질이 달라질 수 있습니다. TTS 음성이 로컬에 설치되어 있지 않다면 오프라인에서는 발음 기능이 제한될 수 있습니다. 실제 사람의 녹음으로 오인하지 마세요.

## 7. 비밀번호 기능의 보안상 한계 — 중요

**`redpass`는 편의용 클라이언트 측 화면 잠금입니다. 진정한 접근 통제가 아닙니다.**

GitHub Pages는 정적 공개 서비스입니다. `content.js`, `source/*.md` 등의 파일은 로그인 여부와 관계없이 URL을 아는 사람이 직접 조회할 수 있습니다. HTML/JavaScript에 포함된 비밀번호 검증 방식(해시 포함)은 개발자 도구 등으로 분석하거나 우회할 수 있습니다. 즉, 이 기능만으로 **확인된 사용자에게만 파일 다운로드를 제한하거나 개인정보를 보호할 수는 없습니다.**

**진짜 회원 전용 공개를 원할 경우** Cloudflare Access, Netlify Identity 또는 인증·인가를 갖춘 백엔드와 보호된 스토리지 등 서버 측 접근 통제가 별도로 필요합니다. 비공개 또는 유료 저작물, 민감한 기록은 공개 GitHub Pages에 올리지 마세요.

## 8. 데이터 저장·복구

- 학습 메모·진도·복습 문장·즐겨찾기·읽기 기록은 기기 내 브라우저의 `localStorage`에 저장됩니다.
- 사이트는 서버에 기록을 업로드하지 않습니다. 단, GitHub Pages 등 호스팅 업체는 일반적인 접속 로그를 남길 수 있습니다.
- 브라우저 기록·사이트 데이터를 삭제하면 저장 기록도 사라질 수 있습니다. 다른 기기와 **자동 동기화되지 않습니다.**
- `설정 → 학습 기록 백업`으로 JSON 파일을 내려받아 보관하세요. `백업 기록 불러오기`를 통해 복원 가능합니다.
- 브라우저 음성합성 API·서비스 워커(PWA)는 브라우저 구현·보안 정책의 영향을 받습니다.

## 9. 폴더 설명

```
ChunkReadingStudio/
├── index.html                 # 사이트 시작점
├── styles.css                 # 데스크톱·모바일·다크 모드
├── app.js                     # 학습 기능 전체, 프레임워크 없음
├── content.js                 # 60편의 구조화 데이터와 원본 원문
├── service-worker.js          # HTTPS 접속 뒤 오프라인 자산 캐시
├── manifest.webmanifest      # PWA 메타데이터
├── assets/
│   └── icon.svg              # 사이트 아이콘
├── source/                    # 60편 원본 + 2개 목차 문서
├── tools/
│   └── build_content.py      # 원본 마크다운 → content.js 데이터 생성기
├── START_WINDOWS.bat          # Windows 간단 로컬 실행
├── START_MAC_LINUX.sh        # macOS / Linux 간단 로컬 실행
└── README.md
```
