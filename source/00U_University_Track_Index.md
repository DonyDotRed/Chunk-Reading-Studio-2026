# 직독직해 낭독 수필 시리즈 · University Track 목차 (30편)

고등학생 트랙(01–30편)의 같은 주제를 대학 수준(CEFR C1, 약 550–650단어)으로 다시 쓴 오리지널 에세이입니다. 고등학생 트랙이 **문법 구조**를 단계적으로 익히는 데 초점을 맞췄다면, University Track은 **학술적 글쓰기 기술**(문체 전환, 연구 보고, 정의, 논증, 인용, 한계 진술)을 익히는 데 초점을 맞춥니다.

각 편의 구성은 고등학생 트랙과 같습니다(원문 → 1회차 청크 직독직해 → 2회차 문장 직독직해 → 학술 영어 포인트 → 어휘장 → 낭독 기록표). 연구나 문헌을 언급한 편에는 참고 문헌을 붙였습니다.

## 고등학생 트랙과의 연계 학습법

1. 원작 편(예: 01)을 먼저 낭독해 내용을 익힙니다.
2. 같은 주제의 U편(예: U01)을 낭독합니다. 내용이 익숙하므로 학술 어휘와 문장 구조에 집중할 수 있습니다.
3. 각 U편의 학술 영어 포인트에 있는 원작 비교표로 같은 내용이 어떻게 다른 문체로 표현되는지 확인합니다.
